# 슬라이드모션 — 실측된 PPT 모핑을 슬라이드에 넣는 클로드 스킬

발표 슬라이드에 **PPT 모핑 같은 전환 모션**을 넣는 스킬입니다.
슬라이드 내용을 주면 콘텐츠의 **관계 구조**를 읽어 어울리는 모션 후보를 제시하고,
고른 것을 **1920×1080 단일 HTML 슬라이드**로 만들어 줍니다.

**모션 수치는 지어낸 값이 아닙니다.** 유튜브 PPT 모핑 튜토리얼 6편을 받아
프레임 단위로 재서 얻은 값입니다.

---

## 무엇이 다른가

대부분의 슬라이드 도구는 「부드럽게」 같은 형용사로 모션을 지시합니다.
그러면 **빈 칸을 모델이 기본값(`0.3s ease`)으로 채웁니다.**

이 스킬은 **대상 / A→B / 시간 / 이징 / 순서** 다섯 칸을 실측값으로 다 채웁니다.

| | 웹 기본값 (reveal.js) | 이 스킬 (실측) |
|---|---|---|
| 지속 | 1.0초 | 0.30 ~ 0.96초 — **패턴마다 다름** |
| 이징 | `ease` | `cubic-bezier(0.25, 0.1, 0.35, 0.95)` |

공통 이징은 **합동 73점 최소제곱 피팅** 결과입니다.
`ease-in-out` 과 `linear` 가 두 패턴 모두에서 **가장 안 맞는 곡선**이었습니다.

실측이 뒤집은 것은 「부드럽게 시작한다」가 아니라 **대칭성**입니다.
이 곡선은 linear 보다 **느리게 출발해**(초기 기울기 0.40),
**1/4 지점에서 linear 의 1.9배 속도로 피크**를 찍고, **나머지 3/4 을 감속에 씁니다.**
`ease-in-out` 이 안 맞는 건 대칭이라서고, `linear` 는 이 앞무게가 아예 없어서입니다.

## 어떻게 동작하나

```
슬라이드 내용을 준다
      ↓
관계 구조 판별 (순서 / 병렬 중 하나 강조 / 포함)
      ↓
어울리는 모션 후보 2~3개 제시 ──▶ ★멈춘다. 사람이 고른다
      ↓
1920×1080 단일 HTML 로 구현
      ↓
이상하면 증상을 말한다 → 원인을 찾아 고친다
```

**모션은 예쁨이 아니라 콘텐츠의 관계 구조에서 나옵니다.**

| 관계 | 원시동작 | 어떤 슬라이드 |
|---|---|---|
| **순서** — 같은 형식이 차례로 | 창 + 스트립 | 연표, 로드맵, 카운트 |
| **병렬 중 하나 강조** | 요소 A→B | 인물 소개, 요금제, 메뉴판 |
| **포함** — 전체 ↔ 부분 | 카메라 | 지도, 조직도, 목업, 표지→본문 |

불릿 목록에는 모션을 넣을 자리가 없습니다 — 불릿은 관계가 아니라 나열이라서,
**모션을 얹는 게 아니라 내용을 셋 중 하나로 다시 써야** 합니다.
그 재구성까지 제안합니다.

## 들어 있는 것

```
slide-motion/
├─ SKILL.md                  철칙 · 관계 판별 · 게이트 · 공통 상수 · 공통 규격 · 함정 · 수정 루프
└─ references/
   ├─ pattern-01-odometer.md      년도 오도미터   (순서)
   ├─ pattern-02-highlight.md     하이라이팅 승격 (병렬, 한 줄 3개)
   ├─ pattern-03-grid-hero.md     그리드 → 히어로 (병렬, 격자)
   ├─ pattern-04-zoom-through.md  목업 줌스루     (포함)
   ├─ pattern-05-photo-pop.md     사진이 쏙       (⚠️ 근거 약함)
   └─ pattern-06-text-knockout.md 텍스트 녹아웃 줌 (포함, 표지→본문)
```

**자족적입니다** — 쓰는 사람은 측정하지 않습니다.
패턴 문서는 **고른 뒤에만 읽습니다.** 여섯 개를 항상 물고 있으면 대화 내내
컨텍스트를 차지하기 때문에 이렇게 나눴습니다.

## 설치 — 세 가지 방법

### 1. claude.ai 스킬로 (권장)

**[slide-motion-skill.zip 받기](https://github.com/mincheol10007/slide-motion-skill/releases/latest/download/slide-motion-skill.zip)**
→ `설정 > 사용자 지정 > 스킬 > 업로드` 에 그대로 올립니다.

> 저장소의 초록색 **Code > Download ZIP** 버튼으로 받은 파일은 **쓸 수 없습니다.**
> 폴더가 한 겹 더 깊어져(`slide-motion-skill-main/slide-motion/`) 스킬로 인식되지 않습니다.
> 위 링크(릴리스 자산)를 쓰세요.

그 다음 이렇게 부르면 됩니다.

```
슬라이드에 모션 넣어줘
```

> 스킬 업로드에는 **코드 실행(code execution) 활성화**가 필요합니다.
> 플랜 제한은 따로 없습니다.

**어디서 동작하나** — 커스텀 스킬이 적용된다고 공식 문서에 명시된 곳은
**Chat · Cowork · Excel/PowerPoint/Word/Outlook 애드인** 입니다.
그 밖의 화면에서도 되는지는 **확인된 바 없습니다.** 안 되면 아래 3번을 쓰세요.

### 2. Claude Code 스킬로

```bash
git clone https://github.com/mincheol10007/slide-motion-skill.git
cp -r slide-motion-skill/slide-motion ~/.claude/skills/
```

### 3. 그냥 붙여넣기 (업로드가 안 되는 어디서든)

**[`slide-motion/SKILL.md`](slide-motion/SKILL.md) 내용을 통째로 복사해 대화창에 붙여넣어도
똑같이 동작합니다.** 그렇게 쓸 걸 감안해서 쓴 문서입니다.
패턴 상세까지 한 장으로 필요하면 릴리스의 **`slide-motion-full.md`** 를 쓰세요
(SKILL.md + 패턴 문서 6개를 CI 가 이어붙여 만든 것입니다).
맨 뒤에 이 한 줄만 붙이면 됩니다.

```
위 문서를 따라라. 내 슬라이드 내용은 아래와 같다. 먼저 관계 구조를 판별하고
후보를 제시한 다음 멈춰라 — 내가 고르기 전에 만들지 마라.

[여기에 슬라이드 내용]
```

## 근거와 한계

- 실측은 유튜브 PPT 모핑 튜토리얼 6편을 프레임 단위로 측정한 결과입니다 (2026-07).
  **원본 영상은 제3자 저작물이라 이 저장소에 포함하지 않습니다.**
  공개하는 것은 측정한 수치와 직접 쓴 문장입니다
- 표본: 이징 **73점 합동**, 오도미터 시간 **22점**, 하이라이팅 **51점**
- ⚠️ **패턴 5「사진이 쏙」은 실측이 없습니다.** 원본 완성본이 물리 모니터를 카메라로
  찍은 화면이라 프레임 측정이 원천적으로 불가능했고, 값을 빌려 쓴 결과 **재현에 실패**했습니다.
  스킬이 이 패턴을 **먼저 추천하지 않도록** 해 뒀습니다
- ⚠️ **패턴 6「텍스트 녹아웃 줌」은 기하만 실측입니다.** 시간·이징은 빌렸고,
  아직 끝까지 재현해 보지 않았습니다. 메커니즘은 프로토타입으로 검증했습니다
- ⚠️ 캡션 페이드 260ms 는 **추정치**입니다 (프레임 피팅 안 함)

> **측정 가능성이 곧 재현 가능성이었습니다.**
> 완성본이 화면 캡처로 재생되는 영상만 측정이 됩니다. 촬영본은 안 됩니다.

### 실측 ≠ 취향

카탈로그는 "원본이 **어떻게 움직이는가**"이지 "**무엇이 좋은가**"가 아닙니다.
실측과 다른 걸 원하는 건 틀린 게 아니라 **연출 선택**입니다 —
다만 스킬은 바꾼 값을 「연출」이라고 밝힙니다. 둘을 섞으면 나중에 무엇이 근거인지 알 수 없습니다.

## ZIP 은 손으로 만들지 않습니다

**원본은 `slide-motion/SKILL.md` 하나뿐입니다.** ZIP 은 저장소에 커밋하지 않고,
태그를 밀면 GitHub Actions 가 만들어 릴리스에 붙입니다
([`.github/workflows/release.yml`](.github/workflows/release.yml)).

```bash
git tag v1.0.1 && git push origin v1.0.1
```

같은 내용을 두 곳에 두면 한쪽만 고쳐져 **조용히 갈라지기** 때문입니다.
빌드 단계에서 구조도 검증합니다 — `slide-motion/SKILL.md` 가 있는지, 스킬 폴더 밖 파일이
섞이지 않았는지, frontmatter 의 `name` 이 폴더명과 같고 **Agent Skills 규격**
(소문자·숫자·하이픈, 64자, 예약어 불가)을 지키는지.

> ZIP 을 직접 말 일이 있다면 `Compress-Archive` 는 쓰지 마세요 —
> 엔트리 경로에 **역슬래시**를 넣어서 업로드가 깨집니다. 파이썬 `zipfile` 을 쓰세요.
