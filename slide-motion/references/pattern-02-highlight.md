# 패턴 ② 하이라이팅 승격 — 원시동작 ② 요소 A→B

> **관계: 병렬 중 하나 강조.** 인물 소개·요금제·옵션 3안
> 근거: **51점 실측** — 카탈로그에서 가장 강한 측정이다

한 줄에 놓인 카드 3장 중 하나가 넓어지고 나머지가 좁아진다. 가로 아코디언.

## 모션 스펙

- 전환 **380ms** (실측 367~400ms, 전환 5회 전부 일치), 공통 이징
- ★ **카드끼리 직접 넘어가지 않는다. 반드시 균등 상태를 거친다**

```
강조 ──380ms──▶ 균등 ──450ms 유지──▶ 다음 강조 ──1200ms 유지──▶ …
```

### 기하 (슬라이드 폭 1920 기준)

| | 강조 | 축소 | 균등 |
|---|---|---|---|
| 카드 폭 | **1119** | **281** | **512** |
| 카드 높이 | **773** | **427** | 427 |
| 칸 간격 | **33** | — | **105** |

- 카드는 **바닥 정렬**이다. 강조되면 위로 자란다
- **간격도 같이 줄어든다** (105 → 33). 폭만 바꾸면 답답해 보인다
- 강조된 카드에만 본문이 페이드인 (240ms, 120ms 지연)

폭 합 검산: 강조 `1119 + 281×2 + 33×2 = 1747` / 균등 `512×3 + 105×2 = 1746` (1px 오차)

### 카드가 3개가 아니면 — 폭을 푼다

**실측한 건 3개 한 줄뿐이다.** N 이 다르면 아래로 푼다.
이건 실측이 아니라 **실측값(N=3)을 재현하는 일반화**다 — 주석에 그렇게 밝힌다.

```
카드 영역 폭 W = 1747              (1920 무대, 좌우 여백 ≈86)
균등:  card  = (W − 105×(N−1)) / N          gap 105
강조:  small = (W −  33×(N−1)) / (N + 3)    gap 33
       hero  = 4 × small                    ← 실측 폭비 1119:281 = 3.98 ≈ 4:1
```

| N | 균등 card | 축소 small | 강조 hero | 검산 |
|---|---|---|---|---|
| 3 | 512.3 | 280.2 | 1120.7 | **실측 512 / 281 / 1119 과 일치** |
| 4 | 358 | 235 | 942 | `942 + 235×3 + 33×3 = 1746` ✓ |
| 5 | 265 | 202 | 808 | `808 + 202×4 + 33×4 = 1748` ✓ |

> **N 은 3~5 까지다.** 축소 카드가 **200px 아래로 내려가면** 제목 한 줄도 안 들어간다 —
> 한 줄에 세우지 말고 **패턴 ③(그리드 → 히어로)** 으로 간다.
> 높이(427 / 강조 773)와 간격(105 / 33)은 **N 과 무관하다.**

## 구현 규칙

- 폭 변화는 **`grid-template-columns` 전환**으로 한다. `gap` 도 같이 전환한다
- ★★ **트랙을 `fr` 로 쓰지 마라. 반드시 px 로 못 박아라.**
  `fr` 은 트랙 합에 대한 비율이라, 합이 같이 변하면 같은 이징을 걸어도 픽셀 폭의
  진행이 빨라진다 — t=0.1 에서 0.072 여야 하는데 **0.119** 가 된다
- 개별 카드에 `width` 를 transition 하지 마라. `scaleX` 로 흉내내지도 마라 — 글자가 납작해진다
- 상태는 부모의 커스텀 속성으로만 표현하고, 자식은 상태를 모르게 한다

```css
.rack{
  display:grid; align-items:end;              /* 바닥 정렬 */
  grid-template-columns:var(--cols); gap:var(--gap);
  transition:grid-template-columns 380ms cubic-bezier(.25,.1,.35,.95),
             gap                   380ms cubic-bezier(.25,.1,.35,.95);
}
.rack[data-active="none"]{ --cols:512px 512px 512px; --gap:105px }
.rack[data-active="1"]   { --cols:281px 1119px 281px; --gap:33px }
```

## 받은 뒤 확인할 것

1. 균등을 거치는가 (강조1 → 강조2 직행이면 원본의 리듬이 아니다)
2. 간격이 같이 줄어드는가
3. 트랙이 px 인가 (`fr` 이면 눈에는 잘 안 보여도 이징이 어긋난다)
4. 카드가 3개가 아니라면 폭을 **공식으로 풀었는가** (눈대중으로 나눴으면 합이 안 닫힌다)
