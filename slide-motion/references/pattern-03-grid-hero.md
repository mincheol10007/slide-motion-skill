# 패턴 ③ 그리드 → 히어로 — 원시동작 ② (2차원)

> **관계: 병렬 중 하나 강조** (항목이 많고 격자일 때)
> 근거: 시간은 프레임 차분, 기하는 **재측정 (2026-07-29)**

격자에 놓인 항목 하나가 **제자리에서** 슬라이드 전체로 커진다.

## 모션 스펙

- 그리드 → 히어로 **300ms** (9프레임), 공통 이징
- 그리드 안에서 큰 자리 ↔ 작은 자리 교환 **367ms** (11프레임)
- 나머지 카드는 **자리를 옮기지 않고 있던 자리에서** 페이드아웃 (200ms)

## 기하 (1920×1080) — 2026-07-29 재측정

> ⚠️ **초판 기하는 폐기했다.** 가로가 산술적으로 닫히지 않았다
> (`70+850+34 = 954` 인데 열 시작이 944, 우변에 22px 이 떴다).
> 원본 영상을 다시 받아 **연속 3프레임(f3916·f3918·f3920)** 에서 노란 배경 경계로
> 다시 쟀고, 세 프레임이 완전히 일치했다. **아래는 그 값이며 두 축 모두 닫힌다.**

### 가로 — 합이 1920 으로 닫힌다

```
여백 80 │ 큰 카드 831 │ 틈 33 │ 작은 431 │ 틈 33 │ 작은 431 │ 여백 81
        └────────────── 카드 영역 1759 (x 80..1838) ──────────────┘
80 + 1759 + 81 = 1920 ✓
831 + 33 + 431 + 33 + 431 = 1759 ✓
```

### 세로 — 합이 카드 영역 높이로 닫힌다

```
영역 y 130,  높이 885 (y 130..1014)
427(1행) + 31(틈) + 427(2행) = 885 ✓
```

### 정리

| | x | y | w | h |
|---|---|---|---|---|
| 카드 영역 | **80** | **130** | **1759** | **885** |
| 큰 카드 (그리드) | 80 | 130 | **831** | **885** |
| 작은 카드 | 열 **944 / 1408** | 행 **130 / 588** | **431** | **427** |
| 히어로 | 80 | 130 | 1759 | 885 |

간격 **가로 33 · 세로 31**.

> **초판과 달라진 값**: 영역 x 70→80 · 영역 폭 1790→1759 · 영역 y 141→130 ·
> 영역 높이 873→885 · 큰 카드 폭 850→831 · 세로 간격 21→31.
> **열 x(944·1408)와 2행 y(588)는 초판이 맞았다** — 그 셋은 그대로다.

## 구현 규칙

- ★★ **CSS Grid 로 짜지 마라.** `grid-column` / `grid-area` 는 **애니메이션되지 않는다**
  (`getAnimations()` 가 0을 돌려준다 → 전환 없이 그냥 점프한다). **이 패턴의 결정적 함정**
- ★ **`position:absolute` + `left/top/width/height` 를 px 로 전환**한다.
  절대 위치라 형제에게 리플로우가 전파되지 않는다
- **카드를 `transform: scale()` 로 키우지 마라** — 안의 글자·사진이 찌그러진다
  (무대 전체를 화면에 맞추는 스케일은 별개다. 공통 규격 참조)
- 카드 안 글자는 `font-size` 전환으로 키워도 된다 (절대 위치 요소 내부라 안전)
- ★ 커스텀 속성(`--w` 등)에서 파생된 값을 쓴다면 **그 속성에도 transition 을 따로 걸어라.**
  등록되지 않은 커스텀 속성은 그 자체가 보간되지 않는다

## 받은 뒤 확인할 것

1. 툭 튀지 않고 부드럽게 커지는가 (튀면 Grid 로 짠 것)
2. 제자리에서 커지는가 (가운데에서 새로 나타나면 요소가 이어진 게 아니다)
3. 글자가 안 찌그러지는가
4. 나머지 카드가 제자리에서 사라지는가
