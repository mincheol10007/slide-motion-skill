# 슬라이드모션 — 실측된 모핑을 슬라이드에 넣는다

## 철칙 4개 (어기면 다 갈아엎게 된다)

1. **모션은 예쁨이 아니라 관계 구조에서 나온다.**
   먼저 콘텐츠의 관계(순서 / 병렬 / 포함)를 읽는다. 관계가 없으면 모션도 없다 —
   **모션을 얹지 말고 내용을 먼저 고친다.**
2. **수치는 실측이다. 지어내지 마라.**
   「부드럽게」 같은 형용사로 바꾸지 마라 — **미지정 칸은 모델이 기본값(`0.3s ease`)으로
   채우고, 그러면 원본이 안 나온다.** 값을 요약하거나 반올림하지도 마라.
3. **모션을 고르는 건 사람이다.** 후보 2~3개를 제시하고 **멈춘다**(게이트 ①).
4. **열었을 때 아무것도 저절로 움직이지 않는다.** 발표용 슬라이드다.

> **실측 ≠ 취향.** 카탈로그는 "원본이 어떻게 움직이는가"이지 "무엇이 좋은가"가 아니다.
> 사용자가 실측과 다른 걸 원하면 **틀린 게 아니라 연출 선택**이다.
> 다만 **바꾼 값은 「연출」이라고 말해 준다.** 섞으면 무엇이 근거인지 알 수 없게 된다.

---

## 워크플로우

```
0. 슬라이드 내용 받기
      ↓
1. 관계 구조 판별          ← 이 스킬의 심장
      ↓
   관계가 없다 ──▶ 내용 재구성 제안 ──▶ ★게이트②(사람이 승인)
      ↓ 관계가 있다
2. 후보 2~3개 제시 ──────▶ ★게이트①(사람이 고른다)
      ↓
3. 해당 패턴 문서를 읽고 그대로 구현 (아래 카탈로그의 references/…)
      ↓
4. 그 문서의 「받은 뒤 확인할 것」으로 자가 점검 → 수정 루프
```

**게이트에서는 반드시 멈춘다.** 후보를 제시하고 바로 만들기 시작하지 않는다.

## 1. 관계 구조 판별 (심장)

| 관계 | 신호 | 원시동작 | 슬라이드 예 |
|---|---|---|---|
| **순서** — 같은 형식이 차례로 | 연도·번호·단계가 있다 | **① 창 + 스트립** | 연표, 로드맵, 카운트 |
| **병렬 중 하나 강조** — 동급 N개 | 항목이 대등하고 N개다 | **② 요소 A→B** | 인물 소개, 요금제, 메뉴판 |
| **포함** — 전체 ↔ 부분 | 안으로 들어가거나 밖으로 나온다 | **③ 카메라** | 지도, 조직도, 목업 |

### 판별 질문 셋

1. 항목의 개수가 정해져 있고 **순서가 의미를 갖는가** → ①
2. 항목들이 **대등하고, 한 번에 하나만** 보면 되는가 → ②
3. 한 항목 **안으로 들어가거나** 전체에서 부분으로 좁히는가 → ③

### 불릿 목록이면 — 모션이 아니라 내용을 고친다

불릿은 관계가 아니라 나열이라서 모션을 넣을 자리가 없다. 셋 중 하나로 다시 쓴다.
재구성안을 **글로 먼저 보여주고 승인을 받는다**(게이트 ②). 내용이 바뀌는 결정이다.

---

## 2. 후보 제시 → ★게이트 ①

관계에 맞는 패턴 2~3개를 골라, 각각 **무엇이 움직이나 / 어떤 인상인가 / 왜 이 슬라이드에
맞나** 를 한 문장씩만 쓴다. 그리고 **"어느 쪽으로 할까요?" 로 끝내고 멈춘다.**

> ⚠️ **패턴 ⑤「사진이 쏙」은 먼저 추천하지 않는다.** 실측이 없고 재현에 실패한 패턴이다.

## 3. 공통 상수 — 모든 패턴에 적용

### 이징

```
cubic-bezier(0.25, 0.1, 0.35, 0.95)
```

**오도미터 22점 + 하이라이팅 51점 = 합동 73점 최소제곱 피팅.**

| 곡선 | RMSE(합산) | |
|---|---|---|
| **★ 공통 최적** | **0.0330** | 채택 |
| `ease` | 0.0635 | reveal.js 기본값 |
| `ease-out` | 0.0563 | |
| `linear` | 0.1647 | |
| `ease-in-out` | 0.1668 | 최악 |

**이 곡선의 실제 거동 — 앞무게(front-loaded) 비대칭이다.**

- 초기 기울기 `y1/x1 = 0.40` → **linear 보다 느리게 출발한다**
- **1/4 지점(x≈0.244)에서 linear 의 1.9배 속도로 피크**에 도달한 뒤,
  **나머지 3/4 시간을 감속에 쓴다**
- 진행률: `x=0.10 → 0.084` · `x=0.50 → 0.732` · `x=0.69 → 0.90`

> `ease-in-out` 이 안 맞는 이유는 **대칭이기 때문**이고,
> `linear` 가 안 맞는 이유는 **이 앞무게 자체가 없기 때문**이다.
> "부드럽게 시작한다"는 통념 자체는 맞다. 실측이 뒤집은 건 **대칭성**이다.

### 전환 시간에는 공통 상수가 없다

**0.30 / 0.37 / 0.71 / 0.96초** — 패턴마다 다르다. **움직이는 거리가 멀수록 길다.**
「모핑은 0.5초」 같은 값을 쓰지 마라.

> ★ **눈으로 잰 시간은 물리 시간보다 짧다.** 위 곡선은 **69% 지점에서 이미 진행률 90%**
> 를 지난다 — 그때 「도착했다」고 보인다. 남은 10% 가 나머지 31% 시간에 걸쳐 안착한다.
> **그 안착이 무게감을 만든다. 길어 보인다고 줄이지 마라.**

## 4. 카탈로그 — 고른 패턴의 문서를 읽고 그대로 구현한다

**후보를 제시할 때는 이 표만 보고, 사람이 고른 뒤에 해당 문서를 읽는다.**
각 문서에 모션 스펙 · 기하 · 구현 규칙 · 확인 목록이 다 들어 있다.

| # | 패턴 | 관계 | 문서 | 근거 |
|---|---|---|---|---|
| ① | 년도 오도미터 | 순서 | `references/pattern-01-odometer.md` | 22점 실측 |
| ② | 하이라이팅 승격 | 병렬(3개, 한 줄) | `references/pattern-02-highlight.md` | **51점 실측** |

## 5. 공통 규격 — 어떤 패턴이든 이대로 만든다

- **1920×1080 고정 무대**를 만들고, **무대 전체에만** `transform: scale()` 을 걸어
  화면에 맞춘다(레터박스, `ResizeObserver` 로 갱신).
  브라우저 확대 100% 에서도 잘리지 않아야 한다
- 단일 HTML 파일. 외부 의존은 웹폰트까지만
- ★ **조작은 사람이 한다.** 클릭 / ← → / Space / Esc 로만 움직인다
  - 열었을 때 아무것도 저절로 움직이지 않는다. 첫 화면은 정지 상태다
  - **타이머로 자동 전환하는 코드를 넣지 마라** (`setInterval`·연쇄 `setTimeout` 금지)
  - 자동재생을 굳이 넣겠다면 **기본값은 꺼짐**이고, 사람이 켜야만 돈다
- 전환 중에는 입력을 무시한다. 상태는 절대 인덱스로 들고 양방향으로 설계한다
- `prefers-reduced-motion: reduce` 대응 (전 duration 0)
- 모션 상수는 파일 맨 위에 모으고 출처를 주석으로 밝힌다

### 산출물을 어떻게 넘기나

- **결과는 파일 하나로 낸다.** 파일명은 `slide-motion-<주제>.html`
- 아티팩트를 만들 수 있는 환경이면 **아티팩트로 낸다**(바로 볼 수 있다).
  아니면 작업 디렉터리에 저장하고 **경로를 알려준다**
- 어느 쪽이든 **채팅 본문에 전체 코드를 다시 붙여넣지 않는다.** 무엇을 만들었고
  어디를 확인하면 되는지만 3~5줄로 말한다

### 디자인은 사용자 것이다 — 레퍼런스를 흉내내지 않는다

카탈로그가 주는 것은 **좌표와 시간뿐**이다. 색·글꼴·주제는 하나도 지정하지 않았다.

- 주제·카피·사진·타이포·색은 **전부 새로 고른다**. 정한 이유를 주석 한 줄씩 남긴다
- 폰트는 **역할 3종**으로 나눠 고른다 — (가) 큰 숫자/헤드라인 (나) 국문 본문 (다) 모노 라벨
- **이미지는 플레이스홀더로 두지 말고 실제 사진을 쓴다**(Unsplash 등).
  ★ **다만 외부 이미지는 차단될 수 있다.** `onerror` 로 폴백을 반드시 넣어라 —
  **CSS 그라디언트나 인라인 SVG**로 대체하고 레이아웃은 그대로 유지한다.
  빈 칸이 남으면 안 된다

## 6. 함정 — 카탈로그 전체에 적용

- ★★ **「2단계 커밋」 — transition 을 붙이는 것과 값을 바꾸는 것을 같은 프레임에 하지 마라.**
  스타일이 플러시되지 않아 **전환이 아예 안 걸리고 요소가 순간이동한다**
  (`getAnimations()` 가 0을 돌려준다).
  → transition 을 붙인 뒤 **강제 리플로우(`el.offsetHeight`)** 하거나
  **`requestAnimationFrame` 으로 다음 프레임에** 값을 바꾼다.
  ★ 이게 **「동시 출발」을 조용히 깨뜨린다** — 한쪽은 굴러가는데 다른 쪽만 텔레포트하는데
  눈으로는 "빠르네" 정도로 보여 놓치기 쉽다
- ★ **기능 이름만 적으면 기본값은 모델이 정한다.** 원하는 기본 상태는 **문장으로** 적는다
- ★ **"부드럽게"는 지시가 아니다.** **대상 / A→B / 시간 / 이징 / 순서 다섯 칸**을 다 채운다
- ★ **모핑되는 요소는 슬라이드를 나누지 않는다.** 같은 DOM 노드를 유지하고 상태만 교체한다
- ★ **`var()` 에서 파생된 속성은 그 속성에도 transition 을 따로 걸어야 한다.**
  등록되지 않은 커스텀 속성은 그 자체가 보간되지 않는다
- **`transform`·`opacity` 가 기본이지만 조건부 규칙이다** — 레이아웃 자체가 변하는 효과에는
  `grid-template-columns`(②)나 절대 위치 px 전환(③④⑤)이 정답이다.
  `font-size` 전환도 **절대 위치 요소 내부라면 안전**하다
- ⚠️ **개별 요소를 `transform: scale()` 로 키우지 마라** — 안의 글자·사진이 찌그러진다.
  **단, 1920×1080 무대 전체를 화면에 맞추는 스케일은 예외다**(§5).
  그건 뷰포트 맞춤이지 요소 확대가 아니다
- **PDF·이미지로 내보내면 모션은 전멸한다.** 배포본은 정지 상태 기준으로 따로 설계한다
- **모핑 남용 금지.** 도입부 1회 + 핵심 전환 1~2회가 상한선이다

## 7. 수정 루프 — 증상에서 원인으로

| 증상 | 원인 | 고칠 곳 |
|---|---|---|
| 열자마자 저절로 움직인다 | 타이머가 들어갔다 | §5 |
| 툭 튀고 전환이 없다 | Grid 애니메이션 불가 / 플러시 누락 | ③ · §6 |
| 한쪽만 순간이동한다 | **2단계 커밋 누락** | §6 |
| 글자가 납작해졌다 | `scaleX` 로 폭을 흉내냈다 | ② |
| 안의 내용이 찌그러진다 | 요소를 `scale` 로 키웠다 / 상자 비가 다르다 | ③⑤ |
| 글자만 툭 점프한다 | `var()` 파생 속성에 transition 안 걸었다 | §6 |
| 대상이 옆으로 흘러 나간다 | `transform-origin` 이 슬라이드 중앙 | ④ |
| 이징이 미묘하게 어긋난다 | 트랙이 `fr` 이다 | ② |
| 되감기에서 숫자가 거꾸로 흐른다 | 리셋에 `transition:none` 이 없다 | ① |
| 이미지 자리가 비었다 | 외부 이미지 차단 + 폴백 없음 | §5 |
| 레퍼런스랑 똑같이 생겼다 | 디자인 자유 영역을 안 열었다 | §5 |

**증상이 표에 없으면 추측하지 말고 무엇이 어떻게 보이는지 되묻는다.**
